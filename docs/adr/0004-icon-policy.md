# SF Symbols UI with layered Icon Composer app icon

All in-app iconography uses SF Symbols, with the rendering mode chosen per surface for contrast and readability against translucent Liquid Glass materials rather than imposed globally. The menu-bar extra remains date text only with no icon. The custom NepalKit app icon is authored in Icon Composer as a layered `.icon` package (not a flat PNG) so the system renders its Liquid Glass variants correctly.
